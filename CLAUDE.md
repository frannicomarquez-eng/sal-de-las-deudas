# Proyecto Brote — ropa de bebé

## Logo oficial (NO cambiar)

El logo de Brote está aprobado y es definitivo. Se usa siempre exactamente igual.

- Archivos oficiales: `marca/brote/svg/` (vectores, texto en curvas) y `marca/brote/png/`.
- Especificaciones: `marca/brote/LOGO-ESPECIFICACIONES.md`.
- Referencia visual aprobada: `marca/brote/png/brote-logo-verde.png`.

Reglas:
1. Toda pieza que lleve el logo (etiquetas, guías, packaging, posteos, web) inserta los archivos de `marca/brote/svg/`. Nunca reescribir "Brote" con una fuente ni volver a dibujarlo.
2. La versión principal lleva brote + "Brote" + "ROPA DE BEBÉ" con una línea a cada lado (`brote-logo-verde.svg`, `brote-logo-crema.svg`, `brote-logo-negro.svg`). Usar esa salvo que la persona pida otra.
3. Colores: verde #2F4A3A, crema de fondo #F6F2EA, bajada #5C6B60, líneas #8FAE8B.
4. Si hace falta regenerar los archivos, usar `marca/brote/fuente/make_logo.py` con las fuentes de esa misma carpeta (Fraunces Light, tamaño óptico 144, espaciado −0,027 em). No usar otra versión de Fraunces: la de Google Fonts para computadora se ve distinta.
